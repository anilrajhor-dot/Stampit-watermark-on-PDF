Getting started

Drop PDFs or images (or a whole folder) into the left panel. Configure your watermark on this panel — the centre preview updates live. Hit Process all files to export everything as a .zip or as individual downloads.

Text vs. logo vs. both

The mode switch above chooses whether each file gets a text watermark, an uploaded logo, or both at once, each positioned independently via the Placement tab.

Placement & tiling

Click a cell on the 9-point grid for a single placement, or turn on Tile / repeat to cover the whole page in a repeating pattern (with an optional brick-style stagger). When placement isn't tiled, drag the amber ⊕ handle directly on the live preview to nudge the X/Y offset — it updates the same numeric fields as typing would, so the two are always in sync, and it snaps to page-centre and the margin line as you get close. In Combined mode, text and logo share the same placement by default; tick Position logo independently (Placement tab) to give the logo its own position, offsets, and margin, and its own blue handle on the preview — both handles can be dragged at once. Font size, logo scale, and rotation are set with the sliders or their number fields, not by dragging.

Background box & fit options

Turn on Background box behind text for a stamp-like frame — colour, opacity, padding, and an optional border, all independent of the text's own opacity. Corners are sharp rather than rounded: pdf-lib (the PDF library this app uses) has no built-in rounded-rectangle support, and a hand-built one risks the preview and the exported file disagreeing — sharp corners are guaranteed identical in both. Auto-fit to page width scales the font to fill the available width; Fit within safe margins is more conservative and also accounts for rotation, shrinking the font so a diagonal stamp can't cross the margin line at any angle.

Blend mode

Normal draws the watermark straight on top of the page. Multiply blends it with the content beneath for a softer, more natural look — it doesn't physically move the watermark under the existing text, since a PDF's own content can't be safely reordered without risking corruption.

Page numbering & Bates numbering

Page numbering restarts at your chosen "starting number" for every file. Bates numbering is different — it keeps counting up continuously across every file in the batch, in the order they're listed, which is what legal and audit workflows expect. Use the ▲▼ arrows on each file card to reorder the batch before processing if the Bates sequence needs to follow a specific file order.

Hindi & other Indian-language text

Type Devanagari, Bengali, Tamil, Telugu, Gujarati, Punjabi (Gurmukhi), Kannada, Malayalam, or Odia directly into the watermark or header/footer fields. StampIt detects the script and fetches the matching Noto Sans font automatically. If that download fails (e.g. no internet on first load), you'll see a warning banner instead of blank boxes.

Stamp Library

A stamp is narrower than a preset — it's just the mark itself: text or logo, colour, opacity, rotation, and position. Applying a stamp leaves your page targeting, extras, and output settings exactly as they were, so switching from "DRAFT" to "APPROVED" mid-job never resets your Bates numbering. Eleven built-in stamps are always available as one-click chips; save your own from the current text/logo styling with Save current as stamp. In short: Stamp = the mark, Preset = all watermark settings, Job Profile = a complete named job for Quick Mode, Project = settings plus your actual files.

Presets

Save your current settings as a named preset, duplicate an existing preset under a new name, export them as a JSON file to share with colleagues, or import someone else's. Reset to defaults clears your current settings back to a blank slate without touching your saved presets. StampIt also remembers your current settings automatically between visits — no need to re-save a preset just to pick up where you left off.

Projects

A preset is just your watermark settings. A project is your settings and your actual files, saved together on this device using your browser's local storage (IndexedDB) — nothing is uploaded. Use it when you want to walk away mid-batch and pick the exact same files back up later, or keep a recurring batch (like a monthly statement run) ready to reload. Loading a project replaces your current file batch, so save first if you want to keep what's currently loaded.

Supported files & limits

PDF, JPG, PNG, and WebP, up to 100 MB each. Password-protected PDFs are detected and skipped automatically rather than breaking the batch — you'll see them marked "Locked" in the file list and in the final summary.

Dark mode

Toggle it with the sun/moon button in the top-right corner, or press D. Your choice is remembered on this device. The watermark preview itself always shows the true page and stamp colours — dark mode only changes the app's own interface, not what gets exported.

Selecting files & retrying failures

Uncheck a file to exclude it from the batch without removing it — the Process button always shows exactly how many files it will run on. If any file fails during processing, a Retry failed files button appears so you can fix your settings and re-run just those, instead of the whole batch. Every run also offers a downloadable text report listing the outcome of each file.

Save again & Share

On desktop, output downloads automatically once processing finishes. On phones, StampIt keeps the result in the app first and gives you View, Save and Share actions. If you need it again — a download got blocked, or you closed it by mistake — Save again re-triggers the same download. On a phone or any browser that supports it, a Share… button also appears, handing the actual output file(s) straight to your device's native share sheet (Mail, WhatsApp, Files, AirDrop, and so on) instead of only saving to Downloads.

Privacy & offline use

🔒 Your documents are processed locally in your browser — files are never uploaded anywhere, on any visit, cached or not. StampIt does load its libraries (pdf-lib, pdf.js, JSZip) and Indian-language fonts from public CDNs, so the very first visit needs an internet connection. If sw.js was deployed alongside this file, those libraries and fonts get cached on-device after that, so later visits — even offline — can load and run without internet. This never applies to your documents, only to the app's own code. The pill in the top-right corner shows your current state: 🟢 Online, ✅ Offline Ready (cached and good to go without internet), or 🔴 Offline (no connection right now).

Storage on this device

Presets, projects (including your saved files), Job Profiles, the Stamp Library, and the offline cache all live in this browser's local storage — never uploaded, never synced anywhere. Browsers cap how much a site can store; StampIt warns you if a save fails because that cap is close.

Checking storage usage…

This removes presets, projects, Job Profiles, the Stamp Library, remembered settings, and the offline cache — not anything from the file system on your device. It cannot be undone.

Quick Mode

Toggle ⚡ Quick Mode (top-right) for a streamlined Files → Watermark → Position → Pages → Output → Process flow — the same settings and same underlying configuration as Advanced Mode, just shown one step at a time with the less-common controls (Extras, Help, presets/projects, independent logo positioning) tucked away. Switch back to 🛠 Advanced Mode any time; nothing you've set is lost either way. Job Profiles on the Files step are complete, named starting points for recurring jobs (distinct from the Presets dropdown in Advanced Mode) — save your current setup as one from the Process step.

What's new in v2.3.23 — audit & fix pass

A full control-by-control audit, tracing each one from UI event through to actual output rather than just reading the code. Found and fixed real bugs: clicking "Browse files" or "Browse folder" was also triggering the dropzone's own click handler underneath it, capable of opening a second file picker; switching Extras or Help tab → Quick Mode → back to Advanced Mode could leave two settings tabs simultaneously visible, stacked on top of each other; the background-box opacity slider was the one control in the app missing its paired precise-entry number field; the "🔒 documents processed locally" badge and two other components used a colour pairing that made their text nearly illegible in dark mode (fixed with a proper theme-invariant token, not a one-off patch); Job Profile cards were unfocusable clickable `<div>`s rather than real buttons, unreachable by keyboard or screen reader — the same category of bug already fixed once before for the 9-point placement grid; the six Extras checkboxes (page numbering, header, footer, date, Bates, border) had their labels as plain adjacent text rather than a proper associated `<label>`, so clicking the text didn't toggle them; and several newer controls (Stamp Library chips, the Quick/Advanced toggle, Job Profile buttons) were missing from touch-target sizing on phones/tablets. Also added WebP as a genuine output format (previously PNG/JPG only, despite input already accepting WebP), with an automatic fallback to PNG on browsers that can decode WebP but not encode it. No existing feature was removed or altered in behaviour.
