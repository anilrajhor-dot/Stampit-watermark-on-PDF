Getting started

Drop PDFs or images (or a whole folder) into the left panel. Configure your watermark on this panel — the centre preview updates live. Hit Process all files to export everything as a .zip or as individual downloads.

Text vs. logo vs. both

The mode switch above chooses whether each file gets a text watermark, an uploaded logo, or both at once, each positioned independently via the Placement tab.

Placement & tiling

Click a cell on the 9-point grid for a single placement, or turn on Tile / repeat to cover the whole page in a repeating pattern (with an optional brick-style stagger).

Blend mode

Normal draws the watermark straight on top of the page. Multiply blends it with the content beneath for a softer, more natural look — it doesn't physically move the watermark under the existing text, since a PDF's own content can't be safely reordered without risking corruption.

Page numbering & Bates numbering

Page numbering restarts at your chosen "starting number" for every file. Bates numbering is different — it keeps counting up continuously across every file in the batch, in the order they're listed, which is what legal and audit workflows expect. Use the ▲▼ arrows on each file card to reorder the batch before processing if the Bates sequence needs to follow a specific file order.

Hindi & other Indian-language text

Type Devanagari, Bengali, Tamil, Telugu, Gujarati, Punjabi (Gurmukhi), Kannada, Malayalam, or Odia directly into the watermark or header/footer fields. StampIt detects the script and fetches the matching Noto Sans font automatically. If that download fails (e.g. no internet on first load), you'll see a warning banner instead of blank boxes.

Presets

Save your current settings as a named preset, duplicate an existing preset under a new name, export them as a JSON file to share with colleagues, or import someone else's. Reset to defaults clears your current settings back to a blank slate without touching your saved presets. StampIt also remembers your current settings automatically between visits — no need to re-save a preset just to pick up where you left off.

Supported files & limits

PDF, JPG, PNG, and WebP, up to 100 MB each. Password-protected PDFs are detected and skipped automatically rather than breaking the batch — you'll see them marked "Locked" in the file list and in the final summary.

Dark mode

Toggle it with the sun/moon button in the top-right corner, or press D. Your choice is remembered on this device. The watermark preview itself always shows the true page and stamp colours — dark mode only changes the app's own interface, not what gets exported.

Privacy & offline use

🔒 Your documents are processed locally in your browser — files are never uploaded anywhere. That said, StampIt does load its libraries (pdf-lib, pdf.js, JSZip) and Indian-language fonts from public CDNs, so it needs an internet connection the first time a page loads or a non-Latin font is used. It is not yet a fully bundled offline app.
